# A captured scenario becomes a regression test

Run from repository root:

```sh
python -m examples.regression.demo
```

This executes `test_generated.py` against isolated naive and guarded localhost
receivers. The naive receiver returns HTTP 200 but the generated duplicate test
fails; the guarded receiver passes. The runner succeeds only when both outcomes
are observed. It creates a fresh receiver per run and reports exit codes.

The test file was generated by
[Webhook Regression Kit](https://github.com/sesenface-tech/webhook-regression-kit)
from the kit's synthetic example events and an explicit expected state.
The generated fixture contains masked example email fields; raw addresses and
endpoints are not embedded. Source and resulting data were reviewed locally.
Generation and masking do not require the kit at test execution time.

This is a maintainer-created self-integration. It is not external-user adoption,
a production incident or proof that arbitrary receivers are safe. No production
data or external system was used. Compare the expected receiver state with your
own side-effect invariants before adapting the generated file.
